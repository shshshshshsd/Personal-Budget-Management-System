# Personal Budget Management System

A desktop application for tracking personal expenses and managing category budgets, built with **C#** and **Windows Forms** (.NET Framework).

## Features
- Record transactions by date, amount, and category (Food, Transport, Shopping, Other)
- Input validation: no future dates, positive amounts only, custom category for "Other"
- Set budget limits per category with visual warnings when limits are exceeded
- Filter transactions by date range and view them in a table
- Visualize spending distribution with a pie chart
- Data stored in CSV files

## Tech Stack
- C#
- .NET Framework
- Windows Forms
- System.Windows.Forms.DataVisualization (Charting)

## How to Run
1. Open `WindowsFormsApp1/WindowsFormsApp1.sln` in Visual Studio.
2. Build and run (F5).
3. `transactions.csv` and `budgets.csv` are created automatically on first use.
